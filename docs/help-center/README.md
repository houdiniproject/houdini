# Help center article sources

This folder holds the source text for customer-facing articles in the Help
Scout help center (`help.commitchange.com`). The markdown here is the
version-controlled copy. The live articles are edited in Help Scout.

## Workflow

1. Write or update the article here as markdown, and merge it.
2. Support copies the content into Help Scout, sets the title and category,
   and links the related articles listed at the bottom of the file.
3. If an article is changed in Help Scout, update the markdown here to match.
